# Landing page · Sofía Souza Nutricionista

Landing page da nutricionista Sofía Souza, com duas propostas para a cliente escolher:

- **Proposta A** (`/versao-materno-infantil.html`): foco em materno-infantil e crianças neurodivergentes.
- **Proposta B** (`/versao-geral.html`): público geral, com a área materno-infantil como diferencial.

A raiz (`/`) abre uma página de escolha entre as duas.

O site em si é HTML/CSS estático, em `public/`. A base Next.js fica pronta para migrar para componentes depois.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.
